# Аудиокниги Nova 3.0.0n

1. Книга попадает в «Слушаю» после 5 минут прослушивания. Время накапливается между сеансами; паузы и перемотка не учитываются. Уже добавленные книги остаются на месте.
2. Исправлено открытие книг: повторные нажатия больше не запускают несколько книг подряд, а отменённое открытие не срабатывает позже.
3. На ТВ при переходе к списку книг выделяется первая видимая карточка слева. Возврат к выбранной книге сохранён.
4. Из поиска убраны посторонние рекомендации источников, не соответствующие запросу. Разные издания одной книги по-прежнему отображаются.
