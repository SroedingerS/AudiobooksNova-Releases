# Аудиокниги Nova 3.0.2n

1. Готовая временная копия аудио теперь доступна при повторном открытии записи даже после перезапуска приложения.
2. После возврата связи плеер может продолжить с сохранённого места без повторной загрузки, если эта копия ещё доступна.
3. «КнигаАудио» убрана из списка источников и общего поиска. Скачанные книги и позиции сохраняются.
