# Аудиокниги Nova 3.0.2z

1. В поиске по онлайн-книгам совпадения по названию показываются первыми. Похожие книги появляются после них.
2. В карточках отображаются жанры и полные описания, если источник их передаёт. При наличии русского описания Nova выбирает его.
3. Если в описании указаны автор или чтец, Nova показывает их в соответствующих полях.
