# Аудиокниги Nova 2.9.3d

1. Исправлен режим «Точное название»: имя автора перед названием на странице источника больше не скрывает книгу из результатов.
2. Обычный и точный поиск показывают отдельные озвучки одной книги с разными чтецами.
3. Поиск по циклу учитывает номер книги, который источник дописывает после названия цикла.
4. Прогресс прослушивания разных озвучек на одном источнике хранится отдельно.

Для обновления установите подписанный APK поверх предыдущей версии Nova. Android 6.0 и выше.
