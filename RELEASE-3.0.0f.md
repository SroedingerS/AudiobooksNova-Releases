# Аудиокниги Nova 3.0.0f

1. Книги можно передать в Nova через «Поделиться» или «Открыть с помощью», выбрать файлы вручную либо проверить выбранную папку импорта. Поддерживаются аудиокниги, текстовые книги и PDF; оригиналы не удаляются.
2. Папка импорта запоминается. Повторная проверка добавляет новые файлы без повторного создания уже импортированных книг; копии сохраняются в библиотеке Nova.
3. При импорте нескольких аудиофайлов можно явно собрать их в одну книгу с естественным порядком глав. Для импорта показаны этапы, прогресс и отмена.
4. В настройках читалки добавлен ручной выбор ориентации: «Авто», «Книжная» и «Альбомная». Выбор действует только во время чтения; положение в книге сохраняется при повороте.
5. В списке глав отключено растягивание при прокрутке за границу списка: последняя глава должна оставаться доступной без анимационного отскока. Сохранены оформление, длительности глав и масштабирование текста.
6. Сохранены аудиобиблиотека, прежняя подпись приложения, обновление поверх установленной версии, четыре архитектуры и оптимизация размера APK средствами R8.

SMB1 в этот выпуск не включён. Для сетевых папок по-прежнему нужны SMB2/3 и права чтения. Внутренний закрытый кеш Telegram недоступен другим приложениям: используйте «Поделиться», «Открыть с помощью» либо сохранение в доступную папку.
