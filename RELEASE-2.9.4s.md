# Аудиокниги Nova 2.9.4s

1. При ошибке подготовки скачанной главы плеер показывает сообщение вместо закрытия приложения.
2. Ошибки запуска службы воспроизведения теперь обрабатываются, книгу можно запустить повторно.
3. Причина такого сбоя записывается в системный журнал Android для диагностики планшетов.
