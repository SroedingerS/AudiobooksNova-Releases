# 3.0.1w

1. Скачанная глава подхватывается плеером после завершения загрузки; при восстановлении сначала проверяется локальная копия.
2. Дополнил журнал типами и временем ошибок звукового выхода, состоянием плеера и фактическим видом источника.
3. Журнал включён по умолчанию и вынесен в отдельный раздел настроек. Явное отключение и ручная отправка сохранены.
4. Заменил повторяющийся значок книги у кнопки «Мои закладки» на отдельный значок закладок.
5. При фатальной ошибке Android-аудиовыхода плеер один раз пробует продолжить ту же главу без необязательных системных эффектов.
