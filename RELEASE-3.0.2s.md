# Аудиокниги Nova 3.0.2s

1. Если Android выгрузил Nova во время паузы, кнопка воспроизведения на гарнитуре снова открывает сохранённую главу с прежней позиции. Телефон можно оставить в кармане.
2. При смене обложки книги Nova теперь читает данные в фоне. Это устраняет одну из причин зависания экрана книги.
3. При открытии плеера настройки его кнопок тоже загружаются в фоне. Экран больше не ждёт окончания этого чтения.
