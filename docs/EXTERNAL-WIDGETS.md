# Интерфейс виджетов Nova

Расширение таймера доступно с Nova 3.0.1r. Это протокол подключения; наличие поддержки в конкретном стороннем клиенте проверяет его разработчик.

Доступ по умолчанию выключен. Пользователь разрешает его в «Настройки → Устройство → Сторонние виджеты и лаунчеры». Сейчас принимается только заранее согласованный пакет с проверенной подписью и UID того же профиля Android. Одного объявления permission недостаточно. Другие клиенты автоматически не получают доступ.

Authority основного приложения: `org.audioknigi.nova.externalwidgets`.

## Снимок

`ContentResolver.call(uri, "snapshot", null, null)` возвращает `Bundle`, `schemaVersion=1`.

При `hasBook=true` доступны title, chapter, credits, chapterIndex (с нуля), chapterCount, positionMs, durationMs, playing, reader, positionUnit, speed, bookPercent, bookPercentApproximate, sampledAtElapsedMs и необязательный coverPng. Обложка перекодирована в PNG, до 256 пикселей по большей стороне и 256 КиБ. Это не исходный файл.

Для аудио positionUnit — `milliseconds`; для текста — `chapter_fraction_1000`. `bookPercent=-1` означает, что достоверный общий процент недоступен. Не трактуйте миллисекунды главы как оставшееся время всей книги; при вычислении времени учитывайте speed.

Повторные запросы чаще 250 мс могут вернуть `error=retry_later` и retryAfterMs. Изменение данных сопровождается пустым явным broadcast `org.audioknigi.nova.externalwidgets.CHANGED`, адресованным согласованному пакету. Постоянный опрос не нужен.

## Таймер

Отдельный выключатель «Таймер сна во внешних виджетах» разрешает чтение и команды только таймера текущего плеера. Если согласия нет, полей таймера в снимке нет; запрос изменения запрещён.

Поля:

| Поле | Тип / значение |
| --- | --- |
| sleepTimerSupported | Boolean |
| sleepTimerEnabled | Boolean |
| sleepTimerMode | `off`, `minutes`, `end_of_chapter` |
| sleepTimerPaused | Boolean |
| sleepTimerRemainingMs | Long, остаток на момент чтения |
| sleepTimerDeadlineElapsedMs | Long, deadline в шкале SystemClock.elapsedRealtime; 0 при остановленном отсчёте |
| sleepTimerDurationMinutes | Int, выбранная длительность |

Для отображения активного отсчёта используйте монотонные часы на этом же устройстве, не локальную дату. При `sleepTimerPaused=true` показывайте фиксированный остаток. «До конца главы» не является числом минут. Таймер озвучки текста сохраняет правила своего плеера; не переносите на него поведение аудиотаймера.

Команда: `ContentResolver.call(uri, "sleepTimer", null, extras)`. Разрешены только ключи extras `mode` (String) и `minutes` (Int). Действия:

- `{mode: "minutes", minutes: N}` — установить отсчёт; audio 1–1440, reader 1–180 минут;
- `{mode: "end_of_chapter", minutes: 0}` — остановить после текущей главы;
- `{mode: "off", minutes: 0}` — отменить таймер.

`accepted=true` означает, что команда поставлена в очередь. Перед применением повторно проверяются согласие и текущая книга/плеер. Если за это время они изменились, команда отменяется. `accepted=false` означает отсутствие загруженной цели либо ограничение частоты: `error=retry_later`, `retryAfterMs=250`. Команды принимаются не чаще одной в 250 мс; восстановление данных также отменяет отложенную команду. Для проверки результата перечитайте снимок, соблюдая retryAfterMs. Не показывайте успешное изменение лишь по факту отправки.

Команда не запускает закрытый сервис, не восстанавливает последнюю книгу и не передаёт управление между аудио и TTS. Собственный таймер клиента и таймер Nova — разные функции; не запускайте оба автоматически.

## Границы доступа

Через этот канал не передаются библиотека, очередь, тексты книг, URL, referer, cookies, пути, журнал, аккаунты, ключи, PendingIntent или токен MediaSession. Query, file, insert, update и delete маршруты закрыты. Команды таймера не являются общим управлением плеером.

Отзыв согласия запрещает будущие чтения и отложенные команды, но не удаляет уже сохранённые клиентом копии. Nova не может ограничить отдельные системные разрешения, которые пользователь самостоятельно выдал стороннему приложению.
