# Аудиокниги Nova 3.0.2u

1. В Nova теперь можно подключать свои сайты с аудиокнигами. Откройте «Библиотека» → «Личные источники» → «Добавить сайт». Вставьте адрес каталога или ленты, затем нажмите «Проверить» и «Добавить».
2. Нажмите на название сайта, чтобы перейти к его каталогу. Книги открываются в обычной карточке, а главы запускаются в плеере Nova. Поиск ищет по названиям и авторам на загруженных страницах.
3. Можно хранить больше десяти сайтов и включать до десяти одновременно. Чтобы включить другой сайт при заполненном списке, временно выключите один из активных. Подойдут сайты, которые публикуют открытые ссылки на аудио.
