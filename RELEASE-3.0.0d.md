# Аудиокниги Nova 3.0.0d

1. Исправлен вход в SMB-папки без логина и пароля: сначала гостевой доступ, при отказе — одна попытка анонимного входа.
2. Ошибки SMB различают отказ сервера, неверную папку, недоступный порт и тайм-аут. Подключения с паролем не переводятся в гостевой режим.
3. Последняя аудиокнига запускается из сохранённых глав без ожидания страницы каталога. Истёкшие ссылки восстанавливаются плеером.
4. Добавлено озвучивание текстового слоя PDF на всех поддерживаемых Android: голос, скорость, пауза и переход между страницами.
5. В альбомном режиме PDF управление перенесено сбоку; увеличенный шрифт не забирает всё место у страницы.
6. Сохранён импорт HTML.ZIP, TXT.ZIP, RTF.ZIP и обычных MOBI (PalmDOC, HUFF/CDIC) из OPDS и локальных файлов.
7. Сохранены проверка повреждённых архивов, понятные названия форматов и совместимость локальных папок, аудио и TTS с Android 6–7.
8. Минификация, обфускация и удаление лишних ресурсов сохранены; DjVu не включён.

DjVu в эту версию не включён. MOBI с DRM и отдельный формат KF8/AZW3 не поддерживаются. Архивы с несколькими самостоятельными книгами требуют выбора отдельных файлов.

Для гостевого SMB-доступа оставьте оба поля «Логин» и «Пароль» пустыми. Нужны SMB2/3 и разрешённое чтение общей папки на роутере или NAS. SMB1 не поддерживается.

Для PDF нужен доступный текстовый слой и установленный системный голос. PDF-сканы без текста требуют OCR; в этой версии OCR не включён. Поиск и синхронизация PDF с аудиокнигой пока недоступны.
