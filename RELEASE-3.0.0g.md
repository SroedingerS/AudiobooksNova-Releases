# Аудиокниги Nova 3.0.0g

1. В оформлении читалки добавлен выбор «Прокрутка / Постранично». Листайте тапом по левому и правому краю или кнопками. Позиция сохраняется при смене режима, ориентации и шрифта.
2. Стабилизированы строки списка глав при начале воспроизведения и позднем получении длительности. Зарезервировано место для прогресса и значка длительности, чтобы последняя глава не уходила из видимой области.
3. Импорт проверяет доступность переданного файла и явно переданный запасной URI из «Поделиться». Для отсутствующего файла и отказа в доступе показаны понятные сообщения; доступен повторный выбор сохранённой копии.

## Если книга не импортируется из Telegram / Plus Messenger

Полностью скачайте файл и передайте его через «Поделиться» / «Открыть с помощью». Если клиент передал несуществующий файл или не выдал доступ, сохраните книгу в доступную папку и нажмите «Выбрать файлы» в Nova.

Путь к закрытой папке другого приложения сам по себе не даёт права чтения. Nova не обходит ограничения Android и не удаляет исходные книги. Исправление именно на устройстве автора обращения требует его проверки.

## Совместимость

Сохранены пакет `org.audioknigi.nova`, прежняя подпись, четыре архитектуры, R8 и сжатие ресурсов. Подписанный APK предназначен для обновления поверх установленной Nova.

SMB1 и DjVu не включены. RuStore в этот раз не обновляется.
