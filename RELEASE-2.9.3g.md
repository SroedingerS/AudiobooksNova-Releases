# Аудиокниги Nova 2.9.3g

1. В настройках звука появился усилитель тихих записей с регулировкой от 0 до +12 дБ.
2. Громкость Nova теперь можно связать с системной медиагромкостью: ползунок приложения и аппаратные кнопки работают согласованно.
3. При включении и отключении связанного режима текущая громкость сохраняется без резкого скачка; устройства с фиксированной громкостью продолжают использовать регулятор Nova.

Усиление и связь с системной громкостью по умолчанию выключены. Для обновления установите подписанный APK поверх предыдущей версии Nova. Android 6.0 и выше.
