# Аудиокниги Nova 2.9.2o

1. Телефонная разметка карточек теперь включается по фактическому компактному окну, включая устройства с нестандартным DPI.
2. Высота каждой пары карточек рассчитывается по общим реально присутствующим данным: пустые строки источника, цикла и жанров не добавляются, если их нет у обеих книг.
3. Для телефонных карточек отключён старый минимум высоты 500 dp, удалены избыточный запас при увеличенном шрифте и растягиваемый промежуток перед длительностью.
4. Распознаются маленькие обложки, помещённые источником внутрь портретного файла с большими чёрными, белыми или прозрачными полями.
5. Версия нормализованного кэша повышена, поэтому уже сохранённые маленькие обложки пересчитываются автоматически без очистки данных приложения.

APK подписан прежним сертификатом Nova и устанавливается поверх предыдущей версии.
