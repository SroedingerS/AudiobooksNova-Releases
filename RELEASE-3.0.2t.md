# Аудиокниги Nova 3.0.2t

1. На телефоне и планшете задайте второй шаг в «Настройки» → «Перемотка при удержании». Короткое нажатие перематывает на обычный шаг. Значение 0 отключает удержание.
2. При удалении прослушанной загрузки Nova сразу показывает, что убирает файлы. В конце сообщает результат. Книги, закладки и позиции сохраняются.
3. При перетаскивании ползунка громкости его положение следует за пальцем. В режиме связи с устройством Nova пропускает повторную установку той же ступени громкости.
4. Если Akniga открывает книгу, но не выдаёт Nova главы, в карточке доступна кнопка для открытия плеера сайта.
5. Обновление обложек сохраняет уже загруженную картинку при временной недоступности источника. Для книг из ленты AudioBoo добавлена поддержка дополнительных полей изображения.
