# Аудиокниги Nova 3.0.0a

1. Аудиокниги и читалка объединены: сохранены функции и исправления Stable 2.9.4w.
2. Добавлена библиотека текстовых книг: EPUB, FB2, ZIP/FB2, TXT, HTML, RTF и просмотр PDF.
3. Читалка получила оформление «Ночной кабинет», настройки текста, поиск, закладки и заметки.
4. Доступны импорт папок, OPDS-каталоги, загрузка текстов по ссылке и перенос библиотеки.
5. Добавлены чтение вслух системным TTS и инструменты связи текста с аудиокнигой.
6. Читалку можно выключить в настройках библиотеки без удаления книг и позиций.
7. Сканирование аудио- и текстовых папок показывает ход работы; импорт — обработанные файлы.
8. Сохранено обновление через GitHub поверх предыдущих Stable-версий с прежней подписью.
