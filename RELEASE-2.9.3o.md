# Аудиокниги Nova 2.9.3o

1. Исправлена загрузка целых циклов: ответ 404 после последней страницы теперь считается окончанием списка и не отменяет найденные книги.
2. Если сохранённая ссылка цикла устарела и вернула 404, приложение пробует точный поиск по названию цикла.
3. Добавлено распознавание циклов из актуальной разметки Книгоблуда и «Книги в ухе».
4. Lis10Book теперь получает название цикла, порядок книг и полный состав цикла через API источника.
5. На Akniga восстановлен список логических глав: длинная запись больше не отображается одной огромной главой.
6. Общий аудиофайл Akniga скачивается один раз, а главы воспроизводятся по своим временным границам.
7. Избранное стало независимым для разных источников и озвучек одной книги.
8. При временной проверке Cloudflare AudioBoo приложение использует сохранённый каталог, если он был открыт ранее.

Для обновления установите подписанный APK поверх предыдущей версии Nova. Android 6.0 и выше.
