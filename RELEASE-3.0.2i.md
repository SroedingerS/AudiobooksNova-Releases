# Аудиокниги Nova 3.0.2i

1. Граммофон использует уже полученные отрезки аудио при перемотке. Если нужный отрезок ещё не получен, он загружается с источника.
2. В библиотеке считается прогресс книги с одной главой, когда плеер уже измерил её длительность.
3. При открытии Nova синхронизация с Google Диском выполняет один запрос авторизации.
4. На паузе карточку плеера можно смахнуть в поддерживаемой Android шторке. Место и очередь сохраняются. В инструкции добавлено, как вернуться к точке установки таймера сна.
