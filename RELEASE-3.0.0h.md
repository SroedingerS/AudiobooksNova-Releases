# Аудиокниги Nova 3.0.0h

1. «Выйти полностью» теперь сохраняет позицию озвучивания читалки, останавливает речевой движок и убирает его уведомление вместе с аудиоплеером.
2. Улучшена проверка преждевременного конца онлайн-главы: свежая позиция реально проигранного звука помогает восстановить оборванный поток. Устаревшая позиция не вызывает повтор законченной главы.
3. Прогресс активной главы обновляется отдельно от списка глав, чтобы обновления плеера не сбивали прокрутку; сохранены масштабирование текста и длительности.
4. Добавлен голос из настроек TTS-движка без каталога голосов. Сетевые и неизвестные голоса включаются отдельно, с предупреждением о передаче текста.
5. EPUB с большим числом файлов открывается через индекс архива: картинки не распаковываются все сразу в память. Защита от повреждённых архивов сохранена.
6. При импорте EPUB и FB2 встроенная обложка сохраняется для полки. Выбранная вручную обложка не заменяется, повторный импорт сохраняет позицию чтения.

Для ранее добавленной книги без обложки повторно импортируйте тот же EPUB/FB2: позиция чтения не сбрасывается. Для движка без списка голосов включите «Сетевые голоса и голос движка» в настройках озвучки и выберите голос в приложении движка. По умолчанию передача текста таким движкам выключена.

На Infinix HOT 11S NFC / Android 11 результат правки списка глав ещё должен подтвердить пользователь. Проверка в эмуляторе не заменяет проверку его прошивки.

Сохранены пакет `org.audioknigi.nova`, прежняя подпись, четыре архитектуры, R8 и удаление лишних ресурсов. Для обновления не нужно удалять установленную Nova.

SMB1 и DjVu не включены. RuStore пока не обновляется. Пожелания с 4ПДА о Яндекс Диске и подключаемых источниках пока только проанализированы.
