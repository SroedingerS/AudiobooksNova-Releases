# Аудиокниги Nova 3.0.0b

1. Исправлен выход из приложения с активной вкладкой текстовых книг: «Назад» из чтения возвращает на полку, с корневой полки — в каталог, откуда работает обычный выход.
2. Исправлена подсветка меню книг на ТВ: рамка выделяет только текущий пункт пульта, а удаление больше не выглядит постоянно выбранным.
3. В сторонние аудиокниги добавлены сетевые папки SMB2/3 для домашнего ПК/NAS: адрес, общая папка, подпапка, учётная запись и проверка подключения.
4. Сетевые коллекции сканируются по запросу с индикатором прогресса и отменой. Локальная папка и разные подключения обновляются независимо; при ошибке связи библиотека сохраняется.
5. Сетевое аудио воспроизводится с перемоткой без полного скачивания. Обложки и длительности индексируются, метаданные кэшируются; доступ к серверу — только для чтения.
6. Пароли сетевых подключений хранятся в защищённом хранилище устройства и не передаются в ссылки книг, резервные копии или синхронизацию.

Сетевое прослушивание требует доступа к ПК/NAS. SMB1 не поддерживается. Настройка: «Настройки → Библиотека → Сторонние книги → Сетевые папки».

Имя пакета и подпись сохранены для обновления поверх предыдущих Stable-версий. Требуется Android 6.0 или новее.
