# Аудиокниги Nova 2.9.4v

1. Добавлен режим изменения скорости сразу, без кнопки «Применить»: кнопки −/+ и шаг 0,05×. Прежний режим остаётся доступен в настройках.
2. Добавлен выбор действий для четырёх команд наушников. Настройки локальны для устройства; используются выбранные секунды перемотки.
3. Вложенные папки сторонних книг сканируются отдельно. Диски одной книги объединяются в главы; для вложенных коллекций определяется цикл.
4. Добавлено редактирование названия, автора, чтеца и цикла сторонней книги. Данные сохраняются в Nova и, если разрешено, в nova-book.json рядом с книгой.
5. Скачанные книги можно объединить в новый цикл без перемещения аудиофайлов.
6. На ТВ после удаления книги из «Буду читать» или избранного фокус остаётся на соседней книге, а не уходит в каталог.
7. Исправлена пустая подборка при ограничениях по жанрам: проверяются следующие страницы, а устаревшие результаты не заменяют новый выбор.
8. При восстановлении онлайн-воспроизведения длительность следующей главы больше не затирает сведения о предыдущей.
