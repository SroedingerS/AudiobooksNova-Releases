# Аудиокниги Nova 3.0.2k

1. В списке источников убрали шесть неиспользуемых каталогов. Ранее сохранённые книги остаются в библиотеке.
2. Личный канал можно добавить через «Поделиться». Перед названием личного канала теперь есть значок.
3. Если автор или чтец указан в описании выпуска, Nova покажет его имя. Когда чтец не указан, видно название канала.
4. У радио и трансляций появилась отметка «Прямой эфир». Перемотка появляется, когда эфир её поддерживает.
5. Исправили загрузку глав на Отрубе при открытии книги из каталога.
