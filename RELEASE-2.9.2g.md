# Аудиокниги Nova 2.9.2g

Изменения относительно версии 2.9.2f:

1. Проверка обновлений больше не зависит от лимита GitHub API для общих IP мобильных операторов, провайдеров и VPN.
2. Nova сначала использует отдельный публичный файл метаданных, а при его временной недоступности автоматически переключается на запасной адрес.
3. Технический код HTTP 403 больше не показывается: если недоступны оба канала, приложение предлагает повторить проверку позже.

Требуется Android 6.0 или новее. Обновление устанавливается поверх предыдущей версии Nova с сохранением книг, прогресса, закладок и настроек.
