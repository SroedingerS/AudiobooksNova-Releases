# Аудиокниги Nova 3.0.1s

1. Переключение озвучки текста и аудиокниги стало прямым: настройки голоса открываются отдельно.
2. При отмене выбора аудиозаписи сохраняются прежний режим, позиции и управление озвучкой. Текущая аудиоочередь заменяется после подтверждения выбора.
3. В стартовой странице появился вариант «Последнее занятие»: вернуться к тексту, озвучке или аудиокниге без неожиданного запуска звука.
4. Загрузка следующей главы при озвучивании текста больше не зависит от открытого экрана читалки. Сохраняется панель озвучки после пересоздания окна.
