# 3.0.1t

1. Исправлено отображение ручных циклов скачанных книг в плеере. Книгу можно убрать из цикла, сохранив файлы.
2. Добавлена отключаемая «Моя очередь» для скачанных книг: свой порядок и переход к следующей книге. Таймер сна имеет приоритет.
3. Доработан маршрут кнопок гарнитуры для озвучивания текста. Аудиокниги и читалка сохраняют раздельное управление.
4. В загрузках с неизвестным объёмом больше не показывается ложный нулевой процент; для составных глав отображаются загруженные сегменты.
5. В настройках можно включить выбор нескольких текстовых книг, продолжение при коротких уведомлениях и кнопки точной громкости.
6. Добавлены отключаемые проверка доступности в списке источников и проверка обновлений при возврате в Nova. Постоянного фонового опроса нет.
7. Добавлен компактный виджет 3 × 1, который включается в настройках устройств. Доработано сохранение обложки при обновлении виджета.
