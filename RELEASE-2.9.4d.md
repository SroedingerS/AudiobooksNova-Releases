# Аудиокниги Nova 2.9.4d

1. В карточке книги и через список глав плеера можно выбрать другую озвучку той же книги.
2. Варианты на других источниках ищутся только по отдельному нажатию, без замедления обычного просмотра.
3. При смене чтеца позиция переносится приблизительно; текущая запись остаётся нетронутой, пока новая не загрузится.
