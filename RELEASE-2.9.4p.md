# Аудиокниги Nova 2.9.4p

1. В поиске записи с разными чтецами показываются раньше повторов одной озвучки из нескольких источников; ни одна карточка при этом не удаляется.
2. Загрузка главы после ошибки HTTP 410 повторно получает ссылку с сервера, даже если подробная карточка книги не была сохранена; при временном сбое обновление повторяется.
3. На экране поиска Android TV добавлена кнопка голосового ввода через установленный на устройстве сервис распознавания речи.
4. Локальную резервную копию можно сохранить в выбранную папку; в настройках добавлена кнопка удаления двух внутренних копий с подтверждением.
