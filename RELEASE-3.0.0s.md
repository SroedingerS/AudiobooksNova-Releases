# Аудиокниги Nova 3.0.0s

Вышел новый релиз 3.0.0s

1. Доработал ввод с аэромыши и джойстика на ТВ: поле поиска нажимается по всей ширине, клавиатуру можно закрыть и снова открыть, не уходя с экрана.
2. В настройках ТВ добавил выбор экранной клавиатуры и переход к её системным настройкам — если приставка предлагает ввод с телефона или скрывает клавиши при подключённой аэромыши.
3. Убрал блокирующие проверки обложек при загрузке карточек в каталоге, поиске и библиотеке. Скрытые экраны больше не загружают обложки заранее.
4. Отчёт об ошибках можно сохранить в файл или на подключённый Яндекс Диск / Google Диск, в том числе с ТВ. После сохранения можно очистить только вошедшие в отчёт записи.
5. Убрал лишнюю фоновую авторизацию Google без подключённого Диска. При недоступных сервисах Nova не запрашивает их обновление во время фоновой проверки.
