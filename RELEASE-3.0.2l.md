# Аудиокниги Nova 3.0.2l

1. Вернули привычный экран плеера. У эфира отметка на месте прогресса, перемотка доступна там, где её поддерживает поток.
2. «Слушаю» сохраняет список при переключении между станцией и книгой.
3. У личных каналов известные главы открываются сразу, а данные автора и чтеца берутся из доступной информации.
