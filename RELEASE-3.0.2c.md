# Аудиокниги Nova 3.0.2c

1. «Книга в ухе»: названия книг, открытие ссылок и поиск книги без доступных глав на других источниках.
2. Совместимость старых аудиозакладок и запросов к Audio-Lib и Lis10book.
3. На ТВ курсор HEX при начале редактирования с пульта ставится в конец значения.

Закладки сохраняют точное издание и время. При изменении временной ссылки используется подтверждённая идентичность файла; неопределённый переход не заменяется соседней главой. Заметки и скачанные файлы не удаляются.
Поиск книги на других источниках запускается по кнопке, без автоматического воспроизведения другой озвучки.
