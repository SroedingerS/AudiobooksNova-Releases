# Аудиокниги Nova 2.9.1m

1. Добавлено удобное контекстное меню книги по долгому нажатию на телефонах, планшетах и Android TV.
2. Обновлена компоновка полного плеера в альбомной ориентации и на телевизорах; исправлено отображение обложки при фокусе с пульта.
3. Добавлен импорт поддерживаемых публичных аудиокниг по ссылке с получением доступных метаданных и глав.
4. Источники упорядочены по подтверждённому размеру каталога; исправлены маршруты и подсчёт «Голосом», «Книгоблуда», «Аудиокниг онлайн» и «Слушать книги».
5. Добавлена безопасная проверка обновлений через GitHub Releases. Автоматическое предложение показывается не более трёх раз для одного выпуска; ручная проверка доступна всегда.
6. Добавлен умный таймер сна: расписание по дням недели и времени, длительность, сброс встряхиванием, пять уровней чувствительности, виброотклик и плавное затухание.
7. Автоповтор уже завершившегося таймера намеренно не используется.
8. Проведены полные модульные тесты и релизный статический анализ без ошибок.
