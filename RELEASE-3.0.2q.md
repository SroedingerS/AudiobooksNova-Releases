# Аудиокниги Nova 3.0.2q

1. Если папка сторонних книг временно недоступна, результат последнего чтения сохраняется. Повторить проверку можно в разделе сторонних книг или в настройках.
2. Чтобы перенести книги или станции, откройте свою полку, удерживайте карточку, нажмите «Выбрать», отметьте остальные, нажмите «Перенести» и выберите другую полку.
3. Обычные стрелки плеера переключают станции по порядку полки. Книги между ними пропускаются. Чтобы выбрать эфир по названию, нажмите «Станции».
