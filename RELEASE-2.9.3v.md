# Аудиокниги Nova 2.9.3v

1. Переходы между книгами сохраняют цепочку: из C можно вернуться в B, затем в A и далее в исходный список.
2. В списке книг цикла внутри плеера появилась кнопка открытия описания; возврат ведёт обратно в плеер без потери воспроизведения.
3. Описание скачанной книги можно открыть из развёрнутой карточки в загрузках.
4. В настройках есть необязательное закрытие окна описания повторным нажатием на текст. По умолчанию оно выключено.
