# Аудиокниги Nova 3.0.2j

1. Добавляйте каналы в «Личные источники» и ищите книги внутри выбранного канала.
2. Части одной озвучки с явной нумерацией собираются в порядке глав.
3. Ссылка на 101.ru открывает выбор станций. Сохраните их на полку и переключайтесь в плеере.
4. В библиотеке появился поиск по сохранённым книгам.
5. В эквалайзере можно включить выравнивание громкости речи.
6. В меню плеера можно восстановить звуковой выход с текущей позиции.
