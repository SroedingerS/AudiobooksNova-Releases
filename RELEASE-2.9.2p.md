# Аудиокниги Nova 2.9.2p

1. Отображение обложек в карточках возвращено к проверенной реализации без адаптивного уменьшения изображения.
2. Обложка снова заполняет весь предназначенный для неё блок через режим `Crop` и не становится маленьким изображением по центру.
3. Используется исходный файл обложки без дополнительного автоматического кадрирования, отдельного нормализованного кэша и повторного JPEG-сжатия.
4. Единое поведение восстановлено в каталоге, поиске, библиотеке, карусели и виджете приложения.
5. Исправления высоты карточек и синхронизации необязательных полей из версии 2.9.2o сохранены.

APK подписан прежним сертификатом Nova и устанавливается поверх предыдущей версии.
