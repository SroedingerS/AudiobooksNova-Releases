# Аудиокниги Nova 3.0.2d

1. Поправлена совместимость управления текущей аудиокнигой с часов и браслетов через системный медиатокен.
2. Команды часов управляют открытой записью, без выбора постороннего файла и доступа к библиотеке.
3. Старые команды закрытой книги не запускают её заново. Аудиокнига и читалка сохраняют раздельное управление.

Физическая совместимость зависит от приложения-компаньона часов; в этой версии исправлен воспроизведённый путь системного управления.
