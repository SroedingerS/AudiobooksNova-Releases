# Аудиокниги Nova 3.0.1e

1. Исправлен возврат из проверки AudioBoo: когда страница книги готова, окно закрывается и Nova получает её главы, не дожидаясь загрузки всех картинок сайта.
2. Подтверждённая страница больше не загружается повторно сразу после проверки.
3. Для других книг и каталога используется тот же сеанс AudioBoo. Пока подтверждение действует, короткая автоматическая проверка может завершиться без нового окна.
