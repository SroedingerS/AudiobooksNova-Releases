# Аудиокниги Nova 2.9.2r

1. В загрузках восстановлено отображение времени звучания, когда отдельные главы не содержат длительность, но известна общая длительность книги.
2. В раскрытом списке скачанных файлов теперь наглядно показывается собственная длительность каждой главы.
3. Для ранее скачанных книг недостающая длительность автоматически считывается из локальных аудиофайлов без обращения к серверу.
4. Новые загрузки сразу сохраняют фактическую длительность готового аудиофайла, если источник её не передал.
5. Длительность скачанного цикла рассчитывается по полным длительностям книг; неполная сумма известных глав больше не выдаётся за итоговую.

APK подписан прежним сертификатом Nova и устанавливается поверх предыдущей версии.
