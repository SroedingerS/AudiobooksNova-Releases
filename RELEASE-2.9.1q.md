# Аудиокниги Nova 2.9.1q

Изменения относительно версии 2.9.1p:

1. TV-меню книги полностью переведено на предсказуемое управление пультом с одним явно выделенным пунктом.
2. Открывающая долгая кнопка, её отпускание и повторные события больше не могут запустить случайное действие.
3. Действие выполняется только после отдельного нового нажатия и отпускания центральной кнопки пульта.
4. Удерживание стрелки перемещает выделение только на один пункт; выбранная строка автоматически остаётся видимой.
5. Кнопка «Назад» и стрелка влево закрывают меню без запуска действий.
6. Холодный запуск повторяет бесшумную проверку обновления, если сеть ещё не успела подключиться.
7. Лимит автоматических предложений теперь расходуется только после реального показа окна обновления, а не при скрытой фоновой проверке.
8. Выполнены 250 модульных тестов; release-сборка и Android Lint завершены без ошибок.

Требуется Android 6.0 или новее. Установка обновления подтверждается системным окном Android.
